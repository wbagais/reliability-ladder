## Trigger

- Fires **only** on `record.checks["r1_verdict"] == "REJECT"`.
- The fact to state is in `record.checks["r1_reason"]`.
- It **cannot** fix a record that passed validation — there is no fact to feed back.

## The rule

- State the reason **as a fact**: `"code 999999 does not exist"`.
- **Never as a question**: `"are you sure?"` — that is a different intervention, and it measures prompt suggestibility rather than correction.
- One bounded retry. Not a loop.

## Input boundary

- May read `checks["r1_verdict"]` and `checks["r1_reason"]`. **Nothing else from `checks`.**
- `checks["meddra_term"]` is derived from the answer key. Putting it in a prompt leaks the answer and invalidates every number above.

## Cost

- +1 call per fired record. Because it fires only on rejections, its per-record token cost is low precisely because few records reach it — which is why [[ledger]] divides by records that **entered** the rung, not by the batch.
