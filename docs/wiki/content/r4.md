`ladder/rungs/r4.py` — not written. owner B · Pushpdeep Mishra. **+1 call per record.**

## Role

- A second model scores the record.
- **Must be a different model family from the extractor.** A model judging its own output measures self-consistency, not correctness. `manifest.model.judge` records it.

## Why it runs after voting

- Order is `[0, 1, 3, 5, 4, 2, 6]`. The judge sees what [[r3]] corrected and what [[r5]] voted on, so it grades the best available answer rather than a draft.

## Input boundary

- May read `checks["r1_verdict"]` and `checks["r1_reason"]`. **Nothing else from `checks`.**
- Feeding the judge `meddra_term` leaks the answer key.

## Design notes

- Rung 1 in `observe` mode exists so the judge is graded on the **full unfiltered set**. If rung 1 filtered, rung 4's marginal contribution would no longer be attributable to rung 4.
- Temperature 0, per `manifest.model.temperature`.
