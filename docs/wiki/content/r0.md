## Role

- The only rung that **receives an empty record list**. It is handed `sources` — `{doc_id: text}` — and builds the records every other rung routes.
- One call per document, JSON out, temperature 0.
- Everything above it measures the reliability layers wrapped around this call.

## What it must produce

From the raw post string alone, for every mention:

- **that a mention exists** — that `cramping` is a reaction and `1st pill` is not
- **character offsets** — exact, or [[r1]] fires `span_ungrounded`
- **a SNOMED code**
- `entity_type` — `reaction` or `drug`

## Hard input boundary

- Rung 0 receives `sources`. **Never `docs`.**
- `docs` carries gold spans, gold codes and annotator entity types. A rung 0 that reads them makes rung 1's span check vacuous and its 1.000 span-shift detection an artefact.
- `run.py` passes only `sources`, but nothing enforces it — the constraint is on the implementer.

## Modes: recall vs search

One implementation, one flag. Two implementations would confound tool access with prompting.

| Mode | Behaviour |
|---|---|
| A · `recall` | the model emits a code from memory, no tools. **Manifest default.** |
| B · `search` | the model gets a vocabulary lookup tool |

- `recall` is what "bare LLM" means, and it is what makes rung 1's rejection rate meaningful.
- The A/B is a declared ablation: *does a lookup tool remove errors, or just move them into `overrode_tool`?*

```bash
python -m ladder.rung0_ab --compare
```

## stub_llm.py

The model client `rung0_ab.py` runs against. Ollama.

- Two functions only: `stub(prompt, text, mode) -> (raw, usage)` and `load_items(splits_dir)`.
- **Must not repair model output.** No stripping code fences, no extracting the first `{...}`, no retry on malformed JSON. A parse failure is rung 0's counter-metric; quietly fixing them deletes the measurement.
- The one exception, not a repair: unwrapping Ollama's `/api/generate` transport envelope. Everything inside `.response` passes through untouched.
- `usage` carries real `prompt_eval_count` / `eval_count`, not estimates. Latency recorded per call so p95 is taken over the run.

## Offset recovery

- Landed as a **flag**, so both arms stay measurable — a model that names the right span but miscounts characters is a different failure from one that invents the mention.
