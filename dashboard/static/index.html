Live run one document through the real rungs — an example of the mechanism, not a measurement

The plan page's "Ladder demo" is a static picture over synthetic posts. This tab runs the same ladder for real: your text (or a dev/pool document) goes through ladder.run.run_ladder — rung 0 calls the extractor, rung 1 checks the codes against the vocabulary, rung 2 states a rejection back to the model, rung 3 votes, rung 4 asks the judge, rung 5 abstains, rung 6 prices the queue — into a scratch directory that is read for this view and deleted. Nothing lands under out/, the runs list never sees it, and the test split is refused.
